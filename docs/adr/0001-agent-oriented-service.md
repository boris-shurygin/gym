# ADR-0001: Границы сервиса для работы с агентом

- **Статус:** Принят
- **Дата:** 2026-10-18

## Контекст

Редактирование программ должно происходить через ИИ-агента, а не через сложный редактор в мобильном приложении. При этом приложению тренировок нужны надёжные обычные прикладные операции.

## Решение

Создать сервер приложения с полноценным API и адаптером MCP. Агент может читать историю и редактировать программы через проверяемые операции предметной области. Skill для работы приложения задаст процедуры агента. Мобильный интерфейс и адаптер MCP используют общую серверную бизнес-логику и авторизацию, а не независимо реализуют правила программ.

## Последствия

- Планирование через агента отделено от выполнения.
- Позже можно добавить настольные или альтернативные клиенты.
- Безопасность, аудит и проверки версий относятся к прикладным сервисам.
- Нужно определить стабильные контракты MCP и REST, ориентированные на задачи.

## Не решено

Хостинг, подробные протоколы, стек реализации и конкретные права клиентов MCP.
