# ADR-0021: Python-клиент тренировочного агента

Статус: Принят по прямому запросу пользователя 2026-10-31.

Пользователь не хочет настраивать ChatGPT-коннекторы по ходу разработки и запросил Python-прокладку и скилл её использования. Основной клиент P10 — `python -m gym_agent`, вызывающий те же защищённые MCP-инструменты. Реальная поддержка ChatGPT-коннектора больше не является блокирующей приёмкой выбранного клиента.

Клиент gym-python предварительно зарегистрирован, использует PKCE S256 и точный loopback callback `http://127.0.0.1:8765/callback`. Пользователь один раз разрешает доступ через браузер. На Windows токены хранятся через DPAPI текущего пользователя в игнорируемой `.local/agent-credentials/`, refresh сериализуется файловой блокировкой. Нет plaintext fallback и настройки production. Поддержка иного ОС-хранилища — отдельная работа.

Сам MCP и общий прикладной слой сохраняются. Скилл вызывает Python-команды и не получает токены. Все проверки владельца/scopes/отзыва и одобрение программы в Gym из ADR-0014 остаются обязательными. Прямых SQL/YC-записей агент не выполняет. Публикация программы после её одобрения — отдельное пользовательское действие; вход клиента не разрешает любые будущие изменения молча.
