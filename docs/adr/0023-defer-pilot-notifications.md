# ADR-0023: Отложить эксплуатационные уведомления

- **Статус:** Принят
- **Дата:** 2026-11-01
- **Основание:** при завершении P11 пользователь решил: «думаю пока не надо нотификаций».
- **Заменяет:** только требование настроить и проверить доставку уведомлений в P11 из ADR-0022.

## Решение

Не создавай каналы уведомлений и алерты Monium и не отправляй проверочные письма в рамках P11.
Настройку доставки выполни отдельной задачей, когда пользователь решит её включить. Отсутствие
письма не блокирует завершение P11 в уточнённом объёме. Контакт владельца
`b.shurygin@yandex.ru` в уведомлении о данных сохраняется; будущий получатель оповещений тот же.

Сохрани добровольную диагностику, очищенные журналы Monium, штатные метрики и проверки
readiness/метаданных копий в GitHub Actions. Права и секреты staging не расширяй.
Production и подключение новых пользователей не входят в это решение.

## Последствия

Оператор проверяет состояние в Monium и Actions вручную. Отдельного гарантированного
канала оповещений Gym нет; успешный workflow не доказывает получение письма. GitHub schedule
работает по возможности, поэтому интервал расписания 15 минут не является SLA обнаружения.
Перед включением уведомлений проверь адрес получателя и фактическую доставку.

Остальные требования ADR-0022, включая отдельный буфер диагностики и проверку восстановления,
сохраняются. Недоступный физический Android остаётся явно записанным ограничением приёмки;
эмуляция не считается проверкой реального устройства.
