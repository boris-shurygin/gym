# Начать или продолжить этап Gym

Прочитай [процесс разработки](../../../docs/development-workflow.md), затем README, применимые AGENTS.md, [план](../../../docs/development-plan.md) и [текущий журнал](../../../docs/development-log.md). Прочитай индекс ADR и относящиеся к этапу решения/спецификации; для инфраструктуры также CI/CD.

1. Проверь рабочее дерево, ветку, remote и изменения origin/main. Сохрани исходные правки пользователя. Не утверждай, что main актуален, если получить его не удалось.
2. Продолжи активный незавершённый пункт. Для состояния «На проверке» продолжи полировку по замечаниям; для «PR открыт» проверь ревью/CI и не начинай новый этап. Если активный пункт уже слит, сверяй это с GitHub и переходи к первому доступному пункту плана. При недоступном GitHub не выдумывай факт merge.
3. Скажи ID, границы результата и проверки. Для нового пункта создай ветку от актуального main; для продолжения используй существующую ветку, проверь изменения main и безопасно учти их. Если удалённое состояние недоступно, продолжай независимую локальную подготовку с явным ограничением, не выдавая её за проверенную интеграцию с main.
4. Выполни только выбранный пункт. Если он слишком велик для проверяемого PR, сначала выдели подпункт в плане. Не превращай открытые вопросы в утверждённые решения: запиши допущения и получи ответ на действительно блокирующие выборы, продолжая независимую работу.
5. Обнови план и журнал: состояние, базовый SHA, ветка, результат, проверки, нерешённые замечания и точка продолжения. Не подменяй реальные проверки их описанием.
6. Переведи результат в «На проверке», покажи изменения и способ проверки. Заверши ответ вопросом: «Всё ли хорошо с результатом этапа?».

Запрос начала этапа разрешает реализацию в его описанных границах, включая этапы кода. Он не означает переход через все этапы до конца. Не создавай PR, не сливай ветку и не выпускай production в рамках этой команды: эти действия выполняются по отдельным командам пользователя. Если пользователь уже прямо включил такое действие в текущий запрос, учитывай это разрешение и соответствующий навык.
