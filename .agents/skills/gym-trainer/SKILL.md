# Тренировочный агент

Прочитай отдельный [Skill тренировочного агента](../../../skills/gym-trainer/SKILL.md) и работай по нему. Вызывай `python -m gym_agent` из корня проекта с локальным Python `.local/backend-venv/Scripts/python.exe`; PowerShell-обёртка — `scripts/gym-agent.ps1`. Клиент подключён только к staging. Его JSON-интерфейс заменяет ручную настройку коннектора ChatGPT; серверное одобрение программы обязательно.
