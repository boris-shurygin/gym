# Тренировочный агент

Прочитай отдельный [Skill тренировочного агента](../../../skills/gym-trainer/SKILL.md) и работай по нему. Вызывай `python -m gym_agent` из корня проекта с локальным Python `.local/backend-venv/Scripts/python.exe` на Windows или `python3` с установленным `secretstorage` на Linux; PowerShell-обёртка — `scripts/gym-agent.ps1`. По умолчанию используй staging; для каждой production-команды явно указывай `--environment production` и отдельный пользовательский вход. Учётные данные разделены по окружениям и рабочим копиям: на Windows используй DPAPI, на Linux — существующую разблокированную коллекцию Secret Service. Его JSON-интерфейс заменяет ручную настройку коннектора ChatGPT; сервер проверяет публикацию. По ADR-0026 доверенному Python-агенту можно один раз выдать `program:publish_direct` через `login --allow-program-publish`, затем публиковать по явному запросу в чате. Без этого права сохраняется одобрение каждой программы в Gym.
